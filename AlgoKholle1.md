# 🎓 Khôlle PHP & Algorithmique

Une application web interactive pour s'entraîner aux khôlles et examens d'algorithmique et de programmation PHP.

## 🚀 Fonctionnalités

- **40 exercices pratiques** répartis sur 8 thèmes fondamentaux (du niveau débutant à avancé).
- **Éditeur de code intégré** (Monaco Editor / VS Code).
- **Exécution PHP en temps réel** directement dans le navigateur via WebAssembly (PHP-Wasm).
- **Validation automatique par cas de tests** (tests unitaires côté client).
- **Mode Khôlle** : Note sur 20, analyse de complexité et retours détaillés.
- **Corrections intégrées** pour chaque exercice.
- **Suivi de progression** sauvegardé localement dans le navigateur (`localStorage`).

## 🛠️ Thèmes couverts

1. Somme de série
2. Résolution d'équation du second degré
3. Somme des valeurs d'un tableau
4. Moyenne des valeurs d'un tableau
5. Inversion des données d'un tableau
6. Vérification d'un palindrome
7. Ajout d'heures, minutes, secondes
8. Valeur maximale dans un tableau
